# 📖 Dictionary App

A responsive dictionary application built with **HTML, Tailwind CSS, and Vanilla JavaScript**.

The application uses an external dictionary API to search for English words and dynamically display their meanings and related information.

## 📖 About The Project

This project was built as a **Frontend Practice Project** to practice building a functional web application that works with real-world data.

Users can search for an English word and get its information through an external dictionary API. The application handles API requests asynchronously and dynamically updates the interface with the received data.

The project focuses on practicing **API integration, asynchronous JavaScript, DOM manipulation, and responsive UI development**.

---

## ✨ Features

- 🔍 Search for English words
- 📖 Display word meanings and definitions
- 🔊 Access pronunciation information
- 📝 Display related word information
- ⚡ Fetch data from an external dictionary API
- 🔄 Handle asynchronous requests with `async/await`
- ❌ Display an error message when a word cannot be found or a request fails
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎨 Responsive interface built with Tailwind CSS

## 🔄 How It Works

1. The user enters an English word in the search field.
2. JavaScript sends a request to the dictionary API using `fetch()`.
3. The request is handled asynchronously using `async/await`.
4. The API returns information about the searched word in JSON format.
5. JavaScript extracts the required information from the response.
6. The UI is dynamically updated with the word's information.
7. If the word cannot be found or an error occurs, an appropriate message is displayed.
